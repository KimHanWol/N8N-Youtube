Personal Video Automation

개인정보처리방침

최종 수정일: 2026년 10월 11일

1. 적용 대상

Personal Video Automation은 운영자가 직접 관리하는 영상 채널의 업로드와 공개 예약을 위한 개인용 도구입니다. 이 방침은 앱이 접근하는 Google 사용자 데이터와 영상 관리 기록에 적용됩니다.

2. 접근하는 정보와 목적

  • OAuth 액세스 토큰 및 갱신 토큰: 승인받은 Google API 작업을 수행하고 연결을 유지하는 데 사용합니다.
  • YouTube 채널 식별자와 채널 정보: 업로드 대상 채널을 확인하는 데 사용합니다.
  • 영상 파일, 제목, 설명, 영상 식별자, 공개 상태와 예약 시각: 영상 업로드와 공개 예약을 수행하고 결과를 기록하는 데 사용합니다.
  • Google Sheets에 저장한 제작 상태와 영상 링크: 작업의 진행 상태를 확인하고 완료된 리소스를 재사용하는 데 사용합니다.

Google 계정 비밀번호는 수집하거나 저장하지 않습니다.

3. 저장 및 처리

OAuth 인증 정보는 n8n의 크레덴셜 저장소에서 관리합니다. 제작 상태와 링크는 운영자가 관리하는 Google Sheets 등에 기록할 수 있습니다. 영상 렌더링과 파일 처리는 운영자의 로컬 컴퓨터 및 워크플로에 연결된 처리 서비스에서 이루어질 수 있습니다. 공개된 영상과 메타데이터는 지정한 YouTube 공개 설정에 따라 표시됩니다.

이 안내 사이트나 공개 GitHub 저장소에는 OAuth 토큰, API 키, 비공개 작업 기록을 게시하지 않습니다.

4. 공유 및 제한적 사용

Google 사용자 데이터는 승인한 영상 관리 기능에 필요한 범위에서만 사용합니다. 해당 작업을 위해 Google, n8n 및 워크플로에 연결된 서비스가 필요한 데이터를 처리할 수 있습니다. Google OAuth 토큰을 이미지·음악·영상 생성 서비스에 전달하지 않습니다.

Google 사용자 데이터를 판매하거나 광고 타기팅, 신용 평가 또는 범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 따릅니다.

5. 연결 해제 및 삭제

Google 계정의 연결 관리에서 앱의 접근 권한을 해제할 수 있습니다. 권한 해제만으로 기존 영상이나 작업 기록이 삭제되지는 않습니다. 운영자는 n8n 크레덴셜과 저장된 작업 기록을 삭제할 수 있으며, YouTube 영상은 YouTube Studio에서 별도로 삭제할 수 있습니다. 정보는 작업 수행 및 운영 기록에 필요한 동안 보관하며, 더 이상 필요하지 않은 인증 정보와 기록은 삭제합니다.
